UNDER THE HOOD

Graphics meet gravity.

The visual experience is built on mathematical ideas from computer graphics and orbital mechanics.

01 / TRANSFORMATIONS
θ

Position in an orbit

Trigonometric functions turn an angle into a 2D position around the Sun.

x = cx + r · cos(θ)
y = cy + r · sin(θ)
02 / ANIMATION LOOP
DRAW→UPDATE→REPEAT

Frame-by-frame motion

Each frame draws the scene, updates angles, and repeats to create continuous motion.

angle = angle + speed
03 / RENDERING
LIGHT

Drawing the scene

Circles, filled ellipses, colours, and labels represent the Sun, planets, and orbital paths.

circle() · fillellipse()
setcolor() · outtextxy()
THE BIG IDEA

A moving world is a changing coordinate.

P(θ) = (cx + r cos θ, cy + r sin θ)
ABOUT THE PROJECT

Built to make
motion visible.

This project explores how computer graphics can represent a familiar physical system. The original simulation is written in C and uses BGI-style drawing functions to render the Sun, planets, and their movement.
